# Logo del panel

Coloca aquí tu imagen PNG con el nombre exacto `logo-rieti.png`.
La barra lateral de todas las pantallas internas utiliza este mismo archivo
para sustituir la R y los textos RIETI / Panel de Control.

Se conserva la proporción dentro de un espacio de 190 × 60 píxeles; puedes usar
un PNG de mayor resolución. Para ajustar el tamaño, modifica
`.brand-lockup__logo` en `../css/styles.css`.
